Wub禁止Windows更新

2026-06-10 · 分享

windows update blocker　简称　Wub，一个禁用windows更新的软件，操作简单。要注意的是禁用windows更新会导致微软应用商店无法使用。下载地址放在最后。

使用方法：

1、应用界面默认英文，可以在menu👉🏻language👉🏻简体中文设置语言。

2、界面很简单，只有两个选项：启用更新&禁用更新，选择一个然后点击应用按钮即可，右边的【✓】代表系统更新正常运行，【×】代表更新被禁用。

3、也可以在菜单的详细服务选项设置禁用或非禁用状态的更新方式。
