无插件|prismjs|实现typecho代码高亮

2026-06-17T10:53:25+08:00 · 听得入迷空间 · 技术教程

插件使用起来很麻烦，所以直接修改主题好了，也是百度的结果，但是不好找，于是在这里记下来。

下载 js 和 css 文件

首先在prismjs选择你需要的语言及插件(不可贪多，选的语言过多，js 文件会很大，严重影响网站加载速度)。

prismjs 很强大，支持全部语言。还有很多功能插件，比如 copy、显示语言、预览等等。

上传文件

把 js 和 css 文件上传到你正在使用的主题的根目录。注意文件名分别是prism.js和prism.css。

插入引用代码

<link rel="stylesheet" href="<?php $this->options->themeUrl('prism.css');?>"> <script src="<?php $this->options->themeUrl('prism.js');?>"></script>Copy

把代码插入到 typecho 的 footer.php 或者 header.php 中就可以了
