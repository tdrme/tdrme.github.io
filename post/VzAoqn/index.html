Docker免费代理加速

2026-06-17T16:14:02+08:00 · 听得入迷空间 · 技术教程

转载自

目前来看免费稳定的方案，网速稍慢，但是能用。

一：需要账户

  1. GitHub

  2. Cloudflare

二：Github

Fork这个项目：CF-Workers-docker.io

三：CloudFlare

1、进入CloudFlare，选择 Workers 和 Pages 。

2、选择 Pages > 连接到 Git > 连接 GitHub。

3、登录成功后选择在 GitHub 中 Fork 的项目。

4、点击保存和部署，后面无需更改。

5、部署成功，点击加速网址。

这个网址就是可以用来镜像加速的网址，也可以自定义域名方便使用。
